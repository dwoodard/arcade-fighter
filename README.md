# Arcade Fighter

Three.js arcade fighting prototype. GitHub Pages deployment from main/root.

## Controls

Desktop: A/D move, W jump, J punch, K kick, L block. Mobile: on-screen touch controls.

## Install

Open the GitHub Pages URL in Safari, tap Share → Add to Home Screen.

Three.js loads from a CDN, so the first launch requires network access. The service worker caches same-origin game files but does not yet bundle the external Three.js dependency for offline play.
